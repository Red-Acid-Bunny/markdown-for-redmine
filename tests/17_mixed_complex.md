## Этап 1. Подготовка инфраструктуры

### 1. Имя сервера

Имя сервера критично для работы тонкого клиента.
Команда:

```bash
sudo hostnamectl hostname <server_name>
```

Проверка:

```bash
hostname -f
```

### 2. Синхронизация времени

Разница часов более 5 минут сломает аутентификацию.
Проверка синхронизации:

```bash
chronyc sources
```

**Особенности настройки DNS**:

- Указанный способ проверен для связки systemd-networkd.
- Файл /etc/resolv.conf часто является динамическим.
- Если ваша система использует NetworkManager,
  добавьте nameserver в соответствующий конфигурационный профиль.
