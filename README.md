# Конвертер Markdown → Textile для Redmine

Инструмент для конвертации Markdown-документов в формат Textile, совместимый с Redmine wiki.

## Описание

Этот проект предоставляет Lua-фильтр для Pandoc, который преобразует Markdown-разметку в Textile-формат, используемый в Redmine. Фильтр учитывает особенности и ограничения Redmine при рендеринге Textile.

## Требования

- **pandoc** 3.x (с поддержкой Lua-фильтров)
- **make**
- **bash** (для запуска тестов)

## Быстрый старт

### Конвертация одного файла

```bash
pandoc --lua-filter=redmine_textile.lua -f markdown -t textile file.md -o file.redmine.textile
```

### Конвертация всех файлов

```bash
make
```

## Поддерживаемые конструкции

| Markdown | Textile (Redmine) |
|----------|-------------------|
| `## Заголовок` | `h2. Заголовок` |
| `\`\`\`bash ... \`\`\`` | `<pre><code class="bash">...</code></pre>` |
| `` `код` `` | `@код@` |
| `- элемент` | `* элемент` |
| `1. элемент` | `# элемент` |
| `**жирный**` | `*жирный*` |
| `*курсив*` | `_курсив_` |
| `[текст](url)` | `"текст":url` |
| `> цитата` | `bq. цитата` |
| `<!-- toc -->` | `{{>toc}}` |

### Особенности

- **Код-блоки**: Поддерживают указание языка (`bash`, `shell`, `xml`, `text` и др.)
- **Экранирование `$`**: Знак доллара в код-блоках автоматически экранируется
- **HTML-комментарии**: Вырезаются при конвертации (кроме `<!-- toc -->`)
- **Таблицы**: Конвертируются в pipe-синтаксис Textile

## Запуск тестов

```bash
# Все тесты
bash test_runner.sh

# Конкретные тесты по номеру
bash test_runner.sh 20 21

# С выводом diff при ошибках
bash test_runner.sh --verbose

# Обновить эталонные файлы
bash test_runner.sh --update
```

## Ограничения

1. **Bold внутри списков запрещён**: `**текст**` внутри элементов маркированного списка ломает Textile-разметку
2. **Уровни заголовков**: Поддерживаются только h1-h4
3. **Вложенные списки**: Преобразуются в плоские (без иерархии)
4. **Blockquote**: Требует поддержки `bq.` в вашей версии Redmine (Textile 2+)

## Пример использования

### Исходный Markdown

```markdown
## Установка

Для установки выполните:

```bash
$ sudo apt install package
```

**Важно**: проверьте зависимости.
```

### Результат (Textile)

```textile
h2. Установка

Для установки выполните:

<pre><code class="bash">
&#36; sudo apt install package
</code></pre>

*Важно*: проверьте зависимости.
```
